# 交付说明 · 鹈鹕：不止一张大嘴

## 入口与启动

- 入口：`output/index.html`（单文件；CSS、JavaScript 与全部原创 SVG 均内联，无图片字体等外部资源）。
- 本地启动：

```bash
python3 -m http.server 5173 --bind 127.0.0.1 --directory output
# 打开 http://127.0.0.1:5173/
```

页面为纯静态实现，可在 iframe 中运行；所有交互状态仅保存在当前页面内存，不使用 localStorage、IndexedDB 或 Service Worker。来源链接只有用户主动点击时才会访问外站，页面本身不请求外网资源。

## 页面内容

- 首屏：原创鹈鹕 SVG 场景、落日/水面动画、旋转“喉囊 ≠ 冰箱”徽章与视差。
- 01 解剖：可点击的喙、喉囊、宽翼、蹼足四个编号与说明联动；喉囊排水演示可切换“排干 / 重新舀水”。
- 02 物种：褐鹈鹕、美洲白鹈鹕、澳大利亚鹈鹕切换；每个物种含分布、觅食、筑巢/保护信息，并明确三种仅为例子。
- 03 觅食：水面舀取、群体围鱼、空中俯冲三种方式，强调俯冲是褐鹈鹕的典型方式而非全类动作。
- 常识核对：三个可翻转的误区卡片。
- 04 生活：群飞/群食介绍，地面巢与树上巢切换，并附“不把一种的繁殖参数当全类规则”的提示。
- 05 守护：四类威胁与“观察者公约”互动清单（4 项，内存进度）。
- 页脚：资料来源（San Diego Zoo Wildlife Alliance、Cornell Lab、Australian Museum）、事实核对日期与原创图形声明。

## 已检查

- 用本地静态 HTTP（`http://127.0.0.1:5173/`）成功加载入口。
- Google Chrome 无头浏览器，桌面视口 1440×1000 与移动视口 390×844 截图检查；页面无横向溢出（`scrollWidth = innerWidth`）。
- 浏览器控制台无 JavaScript 异常。
- 已实际点击/验证：解剖四部位切换、喉囊排水与复位、三个物种标签切换、误区卡翻转、地面/树上巢切换、公约四项勾选并显示 4/4 完成提示。
- 检查了主要版式：首屏、解剖、物种、觅食、常识、生活、守护与页脚。
- 事实表述按 `materials/PELICAN.md` 核对；页面未给出材料未提供的种群数量、保护等级或“所有鹈鹕”的绝对尺寸。

## 未检查

- Safari、Firefox、真实移动触屏、读屏软件与键盘全流程未逐项实测（代码已提供键盘焦点、aria 状态和 reduced-motion 样式）。
- 长时间运行的动画帧率/功耗未做性能剖析。
- 未联网打开页脚来源链接逐条复核（页面按要求不依赖外网）。

## 已知缺陷与说明

- SVG 鸟类图形是风格化原创示意，不用于物种鉴定，比例也不是解剖学精确图。
- 窄屏（≤980px）时物种选择改为横向滚动标签条，需要左右滑动查看第三个物种。
- 页脚来源链接指向外部网站，离线环境下不可访问。
