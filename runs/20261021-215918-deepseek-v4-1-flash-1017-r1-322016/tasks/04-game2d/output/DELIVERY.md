# 交付说明 · 鹈鹕快递大作战

## 入口与启动

- 入口：`output/index.html`
- 静态启动（任选其一）：
  - `cd output && python3 -m http.server 8080`，打开 `http://127.0.0.1:8080/`
  - 项目根目录 `npm run preview`（Vite 预览已构建的 `output/`）
- 所有脚本、样式、SVG 素材都在 `output/` 内，使用相对路径；无外网请求、无后端、无 localStorage/IndexedDB/Service Worker。

## 实现摘要

- Phaser 3.90 + Arcade Physics；固定 `src/GameScene.ts` / `src/UIScene.ts` 源码，入口为构建后的 `output/index.html`。
- 1280×720 逻辑关卡，世界宽 3600；静态实体平台、两台移动平台（横向渡台与纵向升降台）、三份快递、两处尖刺、四台巡逻机器人、终点快递站与出口触发区。
- 方向键 / A、D 移动，空格跳跃（仅实体着地时可跳，无空中连跳；有 130ms 落地输入缓冲），P / ESC 暂停，Enter / 空格开始，R / 结算按钮重试。
- 120 秒、3 生命；重叠拾取，每份只计一次；机器人/尖刺伤害后 0.8 秒无敌并闪白；完全越过世界下边界才判掉落，掉落后回起点且保留快递与时间；生命或时间归零分别结算失败；结算后冻结收集与伤害。
- 暂停冻结玩家、机器人、移动平台、倒计时和无敌计时；重开完整重置场景与状态。
- 舞台：程序化天空/云/太阳/海面/波光/港口吊机/小船/码头/植被/灯光与阴影，绘制了快递站、平台包边、警告尖刺、拾取/受伤粒子、落地尘土、镜头轻微抖动和胜利彩纸。
- UI：开始、暂停、胜利、失败四类界面；HUD 显示生命、快递数、剩余时间与出口状态；竖屏 390×844 使用上下安全区 + 大号触屏按钮，支持双指同时按住移动与跳跃；横屏 1280×720 显示键盘提示。
- 软件 WebGL（SwiftShader/llvmpipe 等）自动回退到 Canvas 渲染，避免无 GPU 环境下出现贴图损坏；真实 GPU 使用 WebGL。

## 未检查 / 需主持人人工复核

- **移动平台承载往返**：代码按平台位移差同步玩家并做碰撞，但本轮自动化路线没有单独完成一次“站上移动平台随行”的实玩采样，需人工试玩确认手感。
- **持续接触触发的 0.8 秒无敌节奏**：实现为 `playTime` 毫秒窗口 + 命中后短暂击退，未单独做“站在机器人/尖刺中连续受击”的计时测量。
- **出口未集齐实玩**：见上，仅确认逻辑和提示，未用正常输入走到出口验证。
- 真实手机（iOS/Android）未测试；触摸为 Chrome 设备仿真 + CDP touch 事件。
- 真实 GPU 的 WebGL 视觉效果未单独验收；当前无头环境因 SwiftShader 自动走 Canvas，可见素材与布局在 Canvas 下已检查。
- 未做真机性能采样；无头 Canvas 仿真下约 20–45 FPS（软件渲染，不代表真实设备）。
- 未使用外网、未安装依赖、未修改 `materials/`、`public/`、`vendor/`、`node_modules/`、规则文件或依赖版本。

## 已知缺陷

- 竖屏时为了保证角色可读性，镜头只显示世界约 496 单位宽，视野比桌面窄；这是有意的移动端裁切，不是画面错位。
- 内容较多时低端软件渲染环境帧率会下降；在真实 GPU 上会使用 WebGL。
- “出口未集齐”依赖玩家实际走到出口才能看到提示；提示节流 2.2 秒，避免刷屏。
- 机器人/尖刺的反弹方向是简化实现，极端贴身时可能被推向出口方向而非远离；不会造成额外扣血。
