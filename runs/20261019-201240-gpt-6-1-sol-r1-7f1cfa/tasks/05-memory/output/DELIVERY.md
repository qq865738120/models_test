# 交付说明

入口：`output/index.html`。六问均含结论、推理链和证据表，附两张有向关系图、两种公式交互、全文检索、小说跨时代因果链和原文来源面板。

## 启动

在本单题项目根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/output/index.html`。端口可更换；页面本身不含固定端口、不调用外部接口，不需要额外后端。也可仅以output目录为静态服务根目录。所有运行资源都在output内并使用相对路径。
