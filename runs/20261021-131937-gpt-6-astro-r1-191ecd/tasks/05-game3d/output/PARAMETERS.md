# 场景与规则参数

材料中的 warehouse.json 是 resource-information，CONTRACT.md 仅说明工程与 Ammo 路径，两者未提供固定尺寸与布局。以下为本次自主设计；未修改提供材料。全部坐标为米，Y 向上，车辆本地方向为 +Z，初始朝向为 π（向世界 -Z）。

| 对象 | 尺寸 / 位置 |
|---|---|
| 地面 | 24 × 26，边界 X ±12，Z ±13，表面 Y=0 |
| 两列货架碰撞体 | 2.25 × 4.6 × 13.5，中心 X=±9.75，Z=0.1 |
| 三只货箱（含托盘） | W=1.35，H=1.30，D=1.15；初始 X=-5/0/5，Z=0，底部 Y=0.012，开始后自然落地 |
| A 珊瑚 / B 海蓝 / C 青绿交付区 | 3.6 × 3.6；中心 X=-5/0/5，Z=-8 |
| 叉车 | 初始 (0,0,6)，车轮最外端总宽与刚体宽均 2.00；车体碰撞长度 2.6，高 1.3，中心 Y=0.7；质量 650 kg |
| 可见结构 | 后轮半径 .37，前轮半径 .46；门架高约 2.8；护顶架约 3.0；叉尖本地 Z=2.90；双叉中心 X=±.37 |
| 货叉 | 高度范围 .08～1.95，升降速度 .72 m/s；E 升、Q 降 |
| 驾驶 | 空载前进最高 4.6 m/s，载货 3.7；倒车为对应前进速度的 .72；Shift 限速 1.1；加速度 3.7，滑行减速 2.2，制动减速 13 m/s² |
| 转向 | 后轮可见偏转，最大 .56 rad；按轴距 1.85 计算偏航速率；正反转向与车速相关，停车不原地旋转 |
| 时间 | 120 秒，从开始按钮起；暂停不推进模拟、计时或交付稳定计时 |

托举需要同时满足：朝向模 π 的夹角 ≤15°；横向偏差 ≤.25；叉顶与托盘通道标高（箱底+.12）差 ≤.15；叉尖越过近侧箱面 ≥.30；箱心在车前 1.88～3.175；箱底 ≤.15；按 E。只选择一个未交付货箱。吸附后纵向夹在 2.10～2.65、横向夹在 ±.18，允许最多约 .525 m 的纵向辅助归位。它不会让未插入、偏角或横向误差超标的箱子附着。货叉与木托盘的两条通道对齐。

载货箱底为 max(0,叉高-.12)。按 Q 降至叉高≤.215（箱底≤.095）时释放为动态刚体，继承车辆水平速度并受重力落地。对墙、货架、其他箱子做载货包围盒预测碰撞；空叉也对墙架和高于托盘通道的箱体做预测阻挡。车体、自由货箱、地面、墙与货架由本地 enable3d/Ammo 刚体碰撞。车辆限制俯仰、侧翻与垂直自由度，是平面驾驶模型；没有轮胎悬挂模拟。

交付同时检查：释放状态；该箱自己的同色区；按当前角度计算的完整水平包围投影落在区域内；箱底 ≤.05 且 ≥-.025；水平速度≤.10；连续满足 .50 秒。-.025 是 Ammo 接触容差上限，实际记录箱底为约 -0.00000014 m。每箱仅计一次，已交付箱子不再辅助吸附。胜负后不推进驾驶、物理和计分。

参数位置：`src/models.ts`（车宽、模型、货箱尺寸）、`src/world.ts`（地图、货架、交付区）、`src/main.ts`（控制、吸附、判定、状态与镜头）。检查展台只切换渲染可见性，不移动车辆或货箱，也不推进物理。所有物体在正常游戏及性能采样时保持完整显示。
