Hyperedge faults remain a major challenge in circuit-level quantum error correction. Accurately
exploiting hyperedge correlations often requires substantial computational resources, which compli-
cates real-time decoding. Matching-based decoders are fast and scalable, but their pairwise graph
representation limits the use of higher-order fault information. Here, we introduce Syndrome Motif
Projection (SMP), a general framework for incorporating hyperedge information into matching-
based decoding. The key idea is that a hyperedge fault produces a characteristic local syndrome
motif. Observing such a motif provides evidence for the corresponding fault. SMP extracts this
information directly from the measured syndrome with linear-complexity preprocessing while pre-
serving the matching backend. It can therefore serve as a lightweight front end to existing scalable
and real-time matching decoders. We demonstrate SMP across surface code memories, color code
memories, and logical gate circuits. On Google’s Willow experimental surface code data, SMP im-
proves both standard and correlated matching and outperforms the tested belief matching baseline.
For color code memories, SMP combined with Chromobius reduces logical failure probabilities by
up to 77.8%. For logical gate circuits, SMP reduces the failure probability of a six-CNOT circuit by
35.5% relative to logical observable matching while achieving performance comparable to iterative
belief matching. These results demonstrate that SMP provides a lightweight and transferable ap-
proach to hyperedge decoding, with a clear path toward integration into scalable real-time decoding
architectures for fault-tolerant quantum computation.
I. INTRODUCTION
Fault-tolerant quantum computation relies on fast and
accurate classical decoding of measured syndromes [1–6].
However, hyperedge faults are a recurring challenge in
circuit-level decoding [7]. A single circuit fault can trig-
ger three or more correlated detection events, forming a
hyperedge in the detector error model [2, 8]. In realistic
quantum computing experiments, hyperedge faults can
arise from circuit-level fault propagation, correlated noise
such as crosstalk [9–12], and fault propagation across log-
ical gate operations [13], and are also intrinsic to the
syndrome structure of several quantum error-correcting
codes [14–17].
Several approaches have been developed to handle hy-
peredge faults. Neural decoders can learn joint syndrome
patterns from data [18–20]. Hypergraph and search-
based decoders can also model multi-detector fault mech-
anisms explicitly [21]. These approaches can achieve high
decoding accuracy, but often require substantial compu-
tation or model complexity [18, 21]. Matching-based de-
coders are a leading practical choice for fault-tolerant
quantum error correction. Fast implementations, paral-
lelization, and windowed architectures make them well
suited to large-scale and real-time decoding [22–25].

Existing matching-based decoders still face a trade-off
between decoding accuracy and computational cost. Cor-
related minimum-weight perfect matching (MWPM) uses
correlations associated with hyperedge faults to reweight
edges in the matching graph [26, 27], but remains less ac-
curate than more powerful decoders [18]. Belief matching
extracts richer hyperedge information through iterative
belief propagation on the circuit-level Tanner graph [2],
but it requires repeated message passing and depends
strongly on the prior fault model [28]. How to exploit hy-
peredge information more effectively without substantial
additional complexity or resource cost therefore remains
an important challenge for matching-based decoding.
Here, we introduce Syndrome Motif Projection (SMP),
a general framework for handling hyperedge faults in
matching-based decoding. The main idea is that a hy-
peredge fault produces a characteristic local syndrome
motif. When nearby detection events match this pat-
tern, they provide evidence that increases the posterior
probability of the corresponding hyperedge fault. SMP
approximates this local evidence and maps it onto the as-
sociated matching edge weights. Unlike belief matching,
which performs iterative inference on the Tanner graph
[2], SMP uses direct local updates to the matching graph.
This provides a lightweight way to exploit hyperedge in-
formation and can be adapted to different codes and cir-
cuit settings.
We demonstrate SMP in three settings: surface code
memories, color code memories, and logical gate circuits.

II. SURFACE CODE DECODING UNDER
CIRCUIT-LEVEL NOISE
The surface code encodes logical information in the
common +1 eigenspace of localX- andZ-type stabilizers,
which generate the stabilizer groupG[30–34]. Figure 1(a)
shows a rotated surface code patch. Measurement qubits
interact with neighboring data qubits to measure these
stabilizers without measuring the encoded logical state.
A Pauli error changes the eigenvalue of each stabilizer
with which it anticommutes. The pattern of changed
eigenvalues is the error syndrome. A decoder uses this
information to infer a recovery operatorRfor the data
errorE. IfRandEhave the same syndrome, the resid-
ual operatorREcommutes with all stabilizers and re-
turns the state to the code space. This alone does not
guarantee recovery of the logical state. Up to an overall
phase, decoding succeeds whenRE∈ Gand fails when
RE∈ N(G)\ G. HereN(G) denotes the Pauli opera-
tors that commute with all stabilizers; those outsideG
act nontrivially on the logical state. The same correction
principle applies to the XZZX code, with its different
stabilizer structure [35–37].

C. Decoder workflow and complexity analysis
For the native surface-code setting, SMP is imple-
mented in the following four steps.
1. Select the three- and four-detector motifsS h de-
fined in Sec. III A, with candidate priorsp h ob-
tained from the DEM as specified in Appendix B.
2. Construct each clusterC h using Eq. (12) to re-
produce the candidate’s detector supportS h and
logical effectℓ h. Obtain its cost proposal from
Eqs. (10) and (11), retaining only valid clusters
with 0≤W C,h < W E,h.
3. For the measured syndrome, evaluate the motif
evidence using Eq. (16) and the three-detector
rule in Appendix B. Update isolated clusters using
Eq. (17) and combine overlapping proposals using
Eq. (18).
4. Decode the complete syndrome on the reweighted
graph using the chosen matching decoder, such as
standard or correlated MWPM, to infer the logical-
observable flips.

A. Decoding across transversal logical gates
Transversal gates offer a route to fast logical opera-
tions when hardware supports interactions between code
blocks, as demonstrated in reconfigurable atom arrays
[51]. Realizing this speed advantage requires reducing the
number of error correction rounds between gates. Joint
decoding across code blocks can reduce this overhead by
accounting for fault correlations across the gates [13].
This principle underlies transversal algorithmic fault tol-
erance, which supports logical computation with a con-
stant number of extraction rounds between operations
[52]. To decode these correlations, matching-based ap-
proaches track error propagation between blocks [53–
55]. Among these approaches, we use logical observ-
able matching (LOM) for its high decoding accuracy in
transversal Clifford benchmarks and efficient matching

VII. DISCUSSION
In this work, we developed Syndrome Motif Projec-
tion (SMP) as a general framework for handling hyper-
edge faults. We have applied SMP to surface codes, color
codes, and logical gate circuits, where it consistently out-
performs the corresponding baseline matching decoders.
This opens several directions beyond the settings stud-
ied here. Lattice surgery provides one example. Merge
and split operations change the stabilizer measurements
and produce new fault motifs [35, 59]. For example,
crosstalk and leakage can generate correlations across
space or time [9–11, 60]. Leakage-reduction circuits and
flag-based extraction can also produce characteristic lo-
cal fault patterns [6, 60, 61].
TheO(d 2r) preprocessing cost derived in Sec. III C
supports efficient implementation. Only activated mo-
tifs require weight updates, so the additional overhead
decreases in the low-noise regime. SMP modifies graph
weights while leaving the matching solver unchanged. It
can therefore be integrated with existing parallel and
sliding-window decoding architectures [1, 22–25, 62]. The
same motif evidence could also guide cluster growth in
weighted union-find decoders, extending the idea beyond
matching [2, 63, 64]. An important next step is to imple-
ment SMP in parallel hardware and measure its end-to-
end decoding latency. Recent real-time decoding demon-
strations provide suitable architectures for testing SMP
at microsecond-scale latency [20, 65].

Appendix A: Local-posterior reference
implementation
This appendix describes the local posterior implemen-
tation used for comparison with SMP. It estimates the ev-
idence in Eq. (8) from allowed local edge configurations
of matching graph edges. It then uses the normalized
posterior to interpolate cluster costs.
1. Candidate hypotheses and local regions
The implementation starts from a geometry-based pre-
decoder catalog. Candidates with intersecting detector
supports are grouped into connected components. The
union of their supports defines a seed region. A greedy
pass examines matching edges connected to the seed de-
tectors in increasing order of their prior weight. It can
join an active seed detector to another active detector or
to a boundary. The touched detector vertices enlarge the
region to Ω. This expansion only defines the local region;
its edges are not assumed to have occurred. Seed regions
or expanded regions containing more than 20 detectors
are skipped.
Each region contains an independent-edge branch and
one branch for each retained candidate. A candidate

[PDF page 15]
15
can contain several hyperedge members and explicitly
included matching edges. Its prior odds are the prod-
uct of the member odds and the included edge odds.
For a single hyperedge this factor isP H. Member priors
are obtained from matching DEM support records when
available; the implementation otherwise uses its motif
type prior. Duplicate descriptions with the same sup-
port, target edges, and recorded logical-observable flips
are merged by adding their relative prior weights. This
is the convention of this comparison implementation. It
differs from the independent-mechanism parity aggrega-
tion in Eq. (B1).
2. Probabilities of local edge configurations
For the independent-edge branch, the required detec-
tor set isY∩Ω. For a candidateh, it is (Y△S h)∩Ω.
In the latter branch, edges touching (Y∩S h)∩Ω are
forbidden. This prevents the residual edge configuration
from reusing an observed detector already attributed to
the candidate. For a composite candidate, its full XOR
support replacesS h in these rules.
The routine collects matching edges connected to at
least one required detector and removes edges touching
a forbidden detector. An allowed local edge configura-
tion uses each required detector exactly once. Other
endpoints are not constrained, except by the forbidden-
detector rule. These rules determine the configurations
included in the local score.
At most eight distinct local edge configurations are
generated for each branch. A greedy completion first
chooses the unassigned required detector with the fewest
available options. It selects the available edge with the
largest prior odds and continues until each required de-
tector has been assigned an edge. Further completions
force one starting edge before applying the same proce-
dure. Edges joining two required detectors are tried first.
Duplicate edge sets are counted once. A failed comple-
tion contributes no mass. The empty required set has
unit relative mass.
Each allowed local edge configuration contributes the
product of its edge odds, as in Eq. (7). The implemen-
tation sums these products using log-sum-exp. The can-
didate branch multiplies this residual mass by its prior
odds. Branches with no allowed local edge configuration
are excluded. Extending the normalization in Eq. (9) to
several competing candidates in the same region gives
