# 鹈鹕图鉴 — 交付说明

- 入口：`output/index.html`。
- 资源：`style.css`、`app.js`、`assets/pelican.svg`，均在 output 内，以相对路径加载。
- 启动：在本题根目录执行 `python3 -m http.server 5187 --bind 127.0.0.1 --directory output`，浏览器打开 `http://127.0.0.1:5187/`。端口可替换，作品本身不依赖固定端口。
- 无需安装、构建或后端；无外网资源请求；状态仅保存在页面内存中。

## 实现

原创 SVG 自然图鉴风格插画；响应式长页，完整介绍形态与适应性、三个代表物种、捕食与食物、群体活动、繁殖育雏、食物网及保护观察。包括身体热点、物种标签与前后切换、两类捕食过程的手动步骤及播放控制、三题观察小测、折叠阅读依据。支持键盘物种切换、焦点提示和系统减少动态效果偏好。

事实依据提供的 materials/PELICAN.md；来源名称在页尾列出。插画和过程动画均明确标注为示意，不用于野外物种鉴别。

## 已实际检查

- 本地静态 HTTP 打开页面，HTML、CSS、JS、SVG 请求均返回 200。
- 桌面浏览器实际查看首页、身体结构、物种与捕食章节。
- 实际操作身体热点、三个物种切换、两种捕食方式、步骤选择、播放/暂停、小测反馈及换题、来源折叠。
- 390px 宽度、仅 `sandbox="allow-scripts"` 的 iframe 中加载页面；检查窄屏排版、移动导航、物种点击与方向键切换、播放控制及来源展开。
- JavaScript 语法检查；HTML 重复 ID、章节锚点、本地资源路径检查；SVG XML 解析检查。
