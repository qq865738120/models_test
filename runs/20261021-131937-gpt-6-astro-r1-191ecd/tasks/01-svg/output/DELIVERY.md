# 鹈鹕骑车送布丁

- 入口：`output/index.html`。全部视觉、样式和动画内联，无外部资源、位图或 JavaScript。
- 启动：在本题根目录运行 `python3 -m http.server 5184 --bind 127.0.0.1 --directory output`，打开 `http://127.0.0.1:5184/`。端口可替换；5173 在检查时已被占用。
- SVG：`viewBox="0 0 640 480"`；SMIL 驱动画面，CSS 驱动下方时间线。一个叙事周期 6 秒，踏板和车轮周期 1.5 秒。

## 实际检查

使用本地 HTTP 服务和真实浏览器查看最终入口。检查页为 `.runtime/check.html`，其测试脚本不属于交付入口；SVG 同步副本为 `solution/animation.svg`。

- 浏览器暂停采样 0、0.375、0.75、1.125 秒，逐一查看四个踏板相位。近侧踏板坐标分别为 (343,337)、(320,360)、(297,337)、(320,314)，远侧与其关于 (320,337) 对称。脚和踏板同组平移，曲柄及腿端点使用相同插值采样；蹼足贴合踏板。
- 查看 1.999、2、2.1、2.76、2.999、3 秒：整车与鹈鹕、固定货架共同颠动，身体与座垫、翅膀与车把保持连接。
- 查看 3.45 秒腾空最高点、3.9 秒落回、4 秒回头开始、4.35 与 4.8 秒回头姿态、5.76 秒恢复和 5.999 秒循环前状态。布丁只向托盘上方位移，最大升高 65 个 SVG 单位，落回原位；提示气泡不遮挡布丁。
- 比较 0、6、12、18 秒，主体包围盒及踏板坐标一致；另查看 5.999 与 6.001 秒衔接。主体在所检查的颠动、腾空、回头极值均完整位于画布内。
- 执行三个周期的连续播放，并检查终点画面。轮转、踏板、路面与事件持续重复，未发现累计漂移。
- 修正检查中发现的路面纹理不可见和后侧踏板遮挡。最终浏览器复查中路面移动可见，1280×720 窗口内可完整显示场景与时间线。
- 静态解析确认 SVG 有效，入口无 script、image、外部 src/href。

## 未检查与限制

未进行多浏览器、移动设备或工作台实际沙箱 iframe 的专门兼容性测试。需支持 SMIL 的现代浏览器。回头采用头部水平翻转配合轻微旋转的卡通表现，身体及双翅保持固定。没有已发现但未修复的功能缺陷。
