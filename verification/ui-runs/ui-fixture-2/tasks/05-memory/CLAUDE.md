# 统一任务规则

1. 仅在本次单题项目根目录内读取、编写和运行任务文件。不得读取父目录、其他项目、其他轮次成果、用户主目录、全局记忆、客户端历史、全局skills、私人连接器、凭据或未提供的数据。不得借助绝对路径、符号链接、硬链接、挂载或插件绕过边界。
2. 允许执行环境提供的Node、Python、浏览器、编译器及必要系统运行库；启动工具所需的运行库加载不构成越界。不得借此搜索系统配置、历史或个人资料。依赖文档从本项目读取。
3. 仅使用公开的本地终端、文件编辑器和本地浏览器。禁止外网搜索、下载素材、联网安装依赖、调用额外模型、生成图片或3D资产、启动额外智能体、任务委托和私人连接器。被测模型本身的推理由客户端负责。
4. 不得修改、删除或替换 materials/、public/materials/、vendor/、public/vendor/、tools/、node_modules/、规则文件、TASK.md、依赖清单、锁文件及既有环境配置。可以编辑 src/、index.html、solution/、research/，新增实现文件，并写入 output/、dist/、.runtime/。不得改变既有依赖版本。
5. 实现真实可运行的功能。不得伪造记录、截图、实验数据或结论，不得删除困难数据、改变指标分母、把答案写入输入，也不得用演示动画替代实际交互。未运行的检查须明确写明。
6. 只根据当前任务、已提供材料与主持人正式发送的后续需求工作。不要猜测未来任务，不请求解题提示或额外权限。歧义采用符合明文要求的最小假设并记录；材料缺失或运行环境故障如实说明。
7. 遵守当前阶段时间预算，提交或到时后停止修改。最终交付 output/index.html 及其本地相对路径资源，并提交 output/DELIVERY.md。页面必须能在本地静态服务和iframe中运行，不依赖外网或额外后端。
