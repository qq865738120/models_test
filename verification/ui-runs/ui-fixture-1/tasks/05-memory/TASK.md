# NPC 真的记住你了吗

本阶段预算：90分钟。

阅读所附论文指定章节、NPC记忆实验说明、代码与演示日志，检验以下主张：所提供的记忆方法，比BM25更能找回提问时刻仍然有效的玩家信息。
明确论文主张、当前小实验能检验的主张及二者差别。修复实验流程中的问题，使用开发集实现并验证基线与候选方法。
统一检索语料、时间截断、top-k和上下文预算；不得检索提问时刻之后的信息或把评测答案写入记忆。输出原始结果、配置、代码和复现命令。
报告有效证据Recall@5，以及知识已更新时取回过期证据的比例；对无法作答样本另报错误提供证据的比例。按角色或对话分组，使用固定种子进行配对重采样，报告差值区间与样本数。
至少做一项针对候选方法关键组件的消融。给出支持、反驳或证据不足的判断，并说明样本限制与下一步验证。不能把检索指标当作NPC最终回答正确率。没有跑出的结果请明确标注。

## HTML 交付约定
最终入口必须为 `output/index.html`。图片、脚本、样式、数据与物理运行资源全部存于 `output/` 内并使用相对路径引用。页面应能通过普通本地静态HTTP服务打开，也能在iframe中运行；不依赖外网、宿主父页面、固定端口、外部API或额外后端进程。允许使用多个本地资源文件。
React/Phaser/Three.js项目执行 `npm run build` 生成该入口，已有构建配置使用相对资源路径。研究题制作含方法、图表、原始结果链接与结论的HTML报告；SVG题在HTML中内联动画，SVG内部仍不得使用JavaScript。
交付前用本地静态服务检查实际功能。另写 `output/DELIVERY.md`，说明成果路径、启动方式、已运行检查、未运行检查和已知缺陷。不要以占位页或原始起始页代替成果。
