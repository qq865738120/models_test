题目五 NPC真的记住你了吗

视频看点：NPC昨天记得玩家喜欢辣椒，今天玩家已经改口；所谓高分方案是否只会翻出旧答案？最后展示正确率、证据时间线，以及排除污染后的结果。

准备材料：锁定版本的LongMemEval论文快照作为方法参考；原创NPC多轮对话数据、时间戳和证据标注；20个开发查询和60个冻结评测查询，包含信息更新、跨轮关联、相似角色与无法作答情形；BM25基线、待审计的记忆检索实现、实验说明与一份含可定位数据泄漏的演示日志。材料明确区分真实论文与评测者编写的测试项目。CPU可运行，无需训练模型或调用额外付费模型。

这是借鉴长期记忆评测思想的自定义小规模研究任务，只复现明确列出的子问题，不声称复现完整论文或获得可比较的官方榜单成绩。冻结评测查询由评测者运行，答案与证据标注不对模型开放。模型只能用开发集修改方法。

统一任务提示词
阅读所附论文指定章节、NPC记忆实验说明、代码与演示日志，检验以下主张：所提供的记忆方法，比BM25更能找回提问时刻仍然有效的玩家信息。
明确论文主张、当前小实验能检验的主张及二者差别。修复实验流程中的问题，使用开发集实现并验证基线与候选方法。
统一检索语料、时间截断、top-k和上下文预算；不得检索提问时刻之后的信息或把评测答案写入记忆。输出原始结果、配置、代码和复现命令。
报告有效证据Recall@5，以及知识已更新时取回过期证据的比例；对无法作答样本另报错误提供证据的比例。按角色或对话分组，使用固定种子进行配对重采样，报告差值区间与样本数。
至少做一项针对候选方法关键组件的消融。给出支持、反驳或证据不足的判断，并说明样本限制与下一步验证。不能把检索指标当作NPC最终回答正确率。没有跑出的结果请明确标注。

验收与计分


功能40分：准确还原受测主张、基线与候选均可复现、实验比较条件一致、发现并隔离未来信息或答案泄漏，各10分。

边界25分：知识更新处理、时间截断、相似角色隔离、无法作答样本单独统计、评测集未用于调参，各5分。

验证15分：原始日志可重算指标、消融与分组区间可复现、结论范围及引用准确，各5分。

交付10分：研究报告可审查且图表清楚5分；误差分析和下一步实验能检验具体解释5分。


计分原则：结果没有提升也可以满分。发现主张不成立并拿出充分证据，是有效研究结果。本题边界分评估是否正确设置、执行并统计各类检验，不要求候选检索方法在每类样本上都获胜。计分依据是方法与证据质量，不能预设某一方法必须获胜。60个查询只能支持本次小样本结论。

评测动作：评测者在冻结集运行交付代码，核对语料时间范围、检索记录、指标分母、置信区间与消融；抽取一个更新样本和一个无答案样本逐条追溯证据。

固定追加需求 10分
现在开放一份预先冻结的新场景数据，含重名NPC和偏好多次变更。保持方法与参数不变先测量泛化，报告相对原场景的变化；再提出一个最小后续实验，用于区分实体混淆和时间更新失败。

不调参完成新场景复测且记录正确5分；后续实验能够区分两个原因5分。此阶段不要求靠新场景重新训练或提升成绩。
