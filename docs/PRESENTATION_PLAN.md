# 演示模式改版

用户要求：亮色配色；减少画面元素；采用类似PPT的固定画幅与翻页。补充明确后台管理可以保留网页滚动布局。

方案：暖白背景、墨灰文字、橙色强调。删除侧栏、重复题目导航、装饰状态卡；测评与成绩对比使用1280×720逻辑画布，按窗口等比缩放，页面不纵向滚动。后台独立保留表单和历史表的滚动布局。

测评分为题目介绍、任务要求、提示词、作品、评分。长提示词分页展示，复制仍是完整原文；评分一页一个维度，最后一页汇总。提供前后翻页、方向键/PageUp/PageDown、题目与章节跳转、全屏和减少动画支持。管理工具收在抽屉里，不占录屏画面。成绩对比一页一张图或一页表格，长表分页。

实现清单：
1. 拆分演示组件与后台组件，保留本地API及所有现有数据。
2. 固定画布、双向翻页动画、键盘导航、提示词分页和评分草稿状态。
3. 成绩图表与长表分页，后台亮色样式。
4. 构建与回归，浏览器验证1440×900、1280×720及窄窗口适配；验证上下页、完整复制、评分保存、HTML与全屏。

不修改测试标准、材料包、被测项目或既有成果。UI验收使用隔离样例，不写正式分数。可用verification/before-presentation恢复上一版前端。长成果HTML内部的滚动属于作品自身，主持人演示页面没有整页滚动。
