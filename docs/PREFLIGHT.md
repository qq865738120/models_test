# 正式开测前的预跑清单

当前工具和材料为试运行版。不要把工程构建通过写成游戏可通关或基准公平性已经验证。

- 所有模型：同操作系统、锁文件、模型档位、客户端工具、上下文与预算；按材料哈希分组；独立新会话、三次运行；明确哪些客户端权限无法统一。
- SVG：固定浏览器，确认SMIL与CSS动画采样方法，覆盖三个循环及踏板四相位。首次交付与追加分别留录屏。
- React：确认参考图可正常查看、10000条数据与接口一致；用正常、乱序、空结果、查询失败和派单失败实际验证参考实现；生产构建校准真实可见反馈的测量方法。公开绘制时机采样只是近似，不单独作为性能过关证据。
- 2D：使用与参赛者相同的原始素材与关卡，开发者实际操作取得三包并通关；站上移动平台、掉出地图、受击、暂停及重开十次；追加易碎包也实际通关。保存参考实现、操作路径与原始录屏。
- 3D：确认本地Ammo正确加载；原车宽及加宽20%均能真实拾放三箱通关；错色、驶过、重复交付和穿模样例应被验收方法识别。统一设备、1280×720与DPR1，校准60秒采样及十次重开资源趋势。
- 研究：核对原论文来源；开发与保留集分组无重叠；信息更新时间与证据标注一致；用代表性错误实现验证可抓住未来信息、同名实体混淆和无答案乱检；分母、消融、配对区间与重复种子可复算。
- 隐藏测试不添加未公开要求；每条隐藏断言映射到公开规则。当前工具提供管理员数据保留与人工验收要求，未实现通用游戏自动评分器。
- 记录阶段预算是否合理，基础设施故障重试规则与评分锚点；确认后冻结材料，所有比较对象使用同一冻结版本。

预跑证据例如保存在评测者控制的 `verification/preflight/`。真实完成后执行：

```sh
python3 bench.py calibrate --note "verification/preflight/ 中的参考实现、视频、测量与审核记录"
```

该命令仅保存主持人声明；不会替你核实这些证据，也不会产生模型成绩。
