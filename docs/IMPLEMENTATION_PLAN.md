# 评测项目工具实施方案 v1

任务来源：当前用户要求将本项目用作多模型评测项目；全自动脚本一键初始化测试项目、生成复制用提示词，并提供禁止读取项目外文件等公平规则。用户已请求执行该能力建设；以下实现限定于本地可撤销的文件和工具，不安装系统服务、不执行被测智能体或对外发布。

## 设计与范围
- 以现有第二版 HTML 为任务提示词与评分原文的唯一来源，不改写原标准。
- Python 标准库管理命令与 macOS 双击入口。构建五题材料包、锁定前端依赖、提供独立工作区及复制提示词页面。
- 初始化仅向指定新运行目录写文件，默认拒绝覆盖；每个模型、题目、重复编号隔离。
- 预装依赖与下载论文发生在准备阶段；正式测试禁止外网、其他模型和额外智能体。运行目录只包含该题公开材料、代码和规则。追加需求保留在评测者控制目录，初始阶段不提前暴露。
- 固定种子和材料 SHA256。保护规则、依赖与公开材料；管理员校验、两阶段快照和运行元数据保存于被测目录外。禁止符号链接逃逸、路径遍历、悄悄覆盖和快照跟随外部链接。
- 普通本地模式仅是规则约束。提供 Docker 断网、仅挂载单题目录、只读材料与非 root 运行的终端命令入口；仅当全部智能体工具实际进入容器才算强制隔离，不宣称约束宿主客户端。容器运行库允许执行，不能借此读取其他业务项目。
- 不实现自动操作模型官网、不调用模型 API、不生成模型成绩。视觉评分与游戏可通关性最终由主持人预跑确认，未确认不标成正式冻结。

## 实施清单
1. 管理 CLI 与双击入口：prepare/init/prompt/check/snapshot/export/doctor。
2. 五道题公共资产与起始工程：SVG 空项目；React/Mock/参考图；Phaser 空场景/素材/关卡；Three.js+enable3d 空场景/布局/物理资源；研究论文/开发数据/检索代码/日志。
3. 公共规则、独立被测根目录、两阶段提示词与哈希清单。
4. 原始记录、不可覆盖快照、上传用 ZIP 与使用文档。
5. 针对跨目录、被保护文件、快照完整性、可重复材料与构建的行为验证。

## 验收
从空运行目录一条命令生成五题可用起始项目与提示词；依赖在准备阶段安装并锁定，正式初始化不访问网络；两个运行目录材料相同且互不复用产物；被保护文件修改、路径逃逸和快照覆盖均能检测或拒绝；前端起始工程构建通过，Mock 的乱序及失败可复现；快照保存完整代码但不复制 node_modules；研究材料区分公开开发集和管理员评测集。

## 风险、验证边界和恢复
Docker 当前未安装，隔离命令只能静态验证并明确未实测；普通模式不能靠规则文件强制安全边界。禁止将浏览器客户端宿主工具宣称为已隔离。游戏素材及布局是新制作的试运行材料，正式排名前须人工预跑及等价参考实现校准。论文快照与 npm 下载有外网依赖，只在 prepare 执行；准备失败不得冒充完整运行。
所有新增工具和运行目录可单独删除恢复；保留原 HTML 不动。不会删除或重置现有运行。计划任务来源：docs/IMPLEMENTATION_PLAN.md 的实施清单。
