# 鹈鹕测评 v1.0 主持人工作台

任务来源：用户要求重新设计提示词页面，剥离主持人评分内容，统一HTML成果，支持内嵌、全屏、历史模型、人工分维度打分、自动加权图表和UI初始化；全部数据本地保存。

## 方案与验收

- React + TypeScript + Vite 前端；Python本地服务复用现有评测初始化与快照流程。只监听127.0.0.1，不发布、不依赖云存储。
- 三个页面：测评工作台、数据看板、后台管理。深色录屏界面、橙色强调、适度入场动效；窄屏可用且支持减少动画。
- 题目内容、考察能力与提示词分区展示；复制内容仅含任务/技术约束/交付要求。规则文件无分值、权重、评分锚点和主持人说明。评分配置仅存主持人侧。
- 五题统一输出output/index.html及相对路径的本地资源。React/游戏统一构建至output；派单Mock采用浏览器内API，保证归档后无需运行模型服务端代码。SVG内联到HTML；研究题提交HTML报告。
- 导入成果时复制文件形成不可覆盖的成果版本，历史轮次可切换。成果在独立只读端口及sandbox iframe展示，允许脚本，限制资源来源并禁止访问主持人API与父页面。支持全屏与重新加载。
- 每题5个0–10分维度，各题权重总和100%；单题为sum(评分×权重/10)，总分为5题等权平均。初始与追加各自打分和比较；没有评分或换成果后的旧评分不算0，也不进入完整总榜。
- 模型可有多轮历史，评分关联具体成果版本；数据看板按同一题目材料与规则版本分组，汇总完整轮次均值，并展示各题、各模型和历史明细。提供本地JSON和CSV导出。
- 后台UI设模型名称、重复编号、题目，后台初始化任务显示进度。可改显示名称、查看路径、归档记录；原测试文件不删除。原pilot记录保留为旧版历史，不与新标准混榜。

## 实施清单
1. 建立新的任务与评分目录，修正提示词/规则生成和HTML交付。
2. 本地API与原子JSON持久化：轮次、初始化、成果归档、评分、历史及导出。
3. 主持人三页前端、全屏播放器、评分表单、对比图表和管理UI。
4. 双击启动入口、说明和旧版记录兼容。
5. 测试提示词分离、评分计算、缺项/失效、持久化、静态资源隔离与越界；浏览器实际验证主要UI流程。

## 风险与恢复
成果HTML是不可信脚本，必须与管理员接口分端口并置于不允许同源的iframe沙箱；管理API校验Host/Origin以及会话令牌，成果服务器只读且限指定成果根路径。不能由界面直接执行被测代码构建。所有修改可撤销，原始标准与既有轮次不改写。完整系统级文件隔离仍由智能体运行环境决定，本次重点是主持人工作台与本地数据。

实施清单1–5已完成；验证结果见 STUDIO_VERIFICATION.md。
