2. 两种“对应”约束了不同的东西

  1. P02从修改的连续性开始。对每一成分假设 ρ̇ᵢ+3H(ρᵢ+Pᵢ)+Ṡρᵢ/(1+S)=0。恒定wᵢ积分得到ρᵢ(z)=ρᵢ₀[1+S(0)]/[1+S(z)]·(1+z)3(1+wᵢ)。因此w=−1也不保证常密度。
  2. 把密度代回第一Friedmann方程。低红移忽略辐射并以H₀归一化，令𝒮=(1+S)/(1+S₀)，则 E²=𝒮−2[Ωm0(1+z)³+Ωde0]。同一个H若由GR分析者拆分，式(34)给出Ωeffde=E²−Ωeffm(1+z)³；式(35)额外选择Ωeffm=Ωm0/(1+S₀)。这一步是模型识别，不是距离观测单独证明的恒等式。
  3. 作者的重建。将原文式(43)的有效w设为目标w(z)，得到一阶ODE(44)，固定χ=ρm0/ρde0>0并从𝒮(0)=1积分；DESI示例取χ=0.45。这个过程把一个函数变成拟合目标的响应函数；只在解存在、𝒮>0且有效密度/分母不奇异的区间有意义，不能从“能写ODE”推出所有z上的全局等价。
  4. 重建曲线与最终似然不是同一对象。最终EXP函数𝒮=1+(β/δ²)z²exp[2(1−z/δ)]，设α=0、𝒮(∞)=1，β>−1、δ>0，收缩了任意函数的自由度。δ为谷位置，β为深度；极小值邻近有效穿越，但式(43)同时有代数项，不能把𝒮′=0无条件当成w=−1的精确充要条件。

A = 接受，F = 逻辑失败，a = P(A)=0.9，rA = P(F|A)

E[获得1个正确且接受结果的尝试数] = 1/[a(1−rA)]

最后两式需要可独立重试、固定接受率的几何等待假设；正确性通常不能在未知计算输出上直接获知，最后一式只是概率账本。若论文给的是每周期条件错误eA，按其绘图定义先还原rA=1−(1−eA)T，所以每次尝试成功且接受为0.9(1−eA)T。这是作者的周期折算，不是对真实时域相关噪声证明独立。若只知抑制因子K=e₀/eA而不知e₀、T及重启代价，总收益仍须保留符号。

4. 两个反事实，分别还缺什么

反事实仍需成立的条件（至少三项）证据等级与可说的结论
交接时作出另一选择① 若指更可信的执剑人，敌方必须在攻击决策前相信其会广播；若只指已经遭袭后按下，不能倒改已发生的发射命令。② 开关流程、设施与通信仍来得及完成广播。③ 即使广播成功，暴露后也须有可靠的长期生存方案。④ 若主张一直保持和平，制度设施、任期与未来敌方策略也须持续有效。敌方在交接时动手、设施迅速毁坏是确定事实；另一人的可信度有智子估计支撑；“按下立刻吓退已发射水滴”与“永远不遭降维”无保证。更可信人选可能维持威慑；此刻广播最多首先改变报复与生存窗口，不能单独保证太阳系不灭。

5. 从个人责任到宇宙责任：没有可相减的账

前期责任对象是具体的敌我、平民与技术组织，信息受威慑模型、审查和局部工程知识限制；“保护眼前生命”可能与维持长期生存能力冲突。最后对象变成所有宇宙生命共享的质量预算，信息来自广播与小宇宙中的宇宙学解释，依然不能观察所有人的返还。两人放弃避难所、返还大量物质，是可确认的新行动，不是对既往死者和文明的恢复。

二维化 / 二向箔 · 空间及其中三维物质封装力场衰退后，三维向二维跌落并扩张；不是仅有爆炸光沿直线传播。内部细节展开；没有厚度，原三维生命死亡，巨行星不能遮蔽。太阳系场景逃逸速度为光速。未展示逆向复原；光速飞船逃出扩展前沿不等于把已经二维化的城市救回三维。
黑域 · 包含恒星系的低光速区将当地c降低到不能逃出该体系的程度；大量曲率航迹扩散相连可形成包裹恒星系的区域。低光速黑洞，不能对外逃离/发送信息，形成安全声明；计算与文明能力受损。光速二号的标准光速微型黑洞没能降低真空c，不能与低光速黑域等同。文本没有展示黑域形成后整体解除；内部不等于必已二维化。DX系统封闭后能否有常c内部区仍有疑问。
死线 · 极强曲率航迹的c≈0核心更高功率的曲率引擎留下极窄线状区域；未扰动时保持，扰动可能扩张成有限低c区域；本次具体扰动不明。核心内运动近乎停止；扩张区低c约10km/s，使电子计算机失灵、飞船受当地速度上限。不等同普通人类飞船航迹；未示逆转。关一帆说人类还造不出；耦合只是可能机制。
647号宇宙 · 独立时空与出入口有周期边界的一公里立方空间；入口识别获授权者；物质由大宇宙搬入，时间相对独立。不能普通双向通信；可接收耗资巨大的超膜广播；门可移动扫描外界环境、运输物质及人员。可经门返还物质和离开，不等于逆转降维或解除黑域；其建造技术、能量机制对人物亦不透明。

两个“逃离”没有共同的保证

星环号在太阳系二维化时沿尚可航行的三维空间用曲率驱动达到当地光速，越过吞噬前沿；它没有把当地光速当成可任意突破的常数。DX3906则是航路环境的光速被降低，任何引擎都受新的本地极限，电子控制也受损。备用神经元计算机和反物质制动让飞船脱离贴近光速的慢速环绕，代价是外界约1890万年；它们没有从已经形成的黑域飞回外部宇宙。
