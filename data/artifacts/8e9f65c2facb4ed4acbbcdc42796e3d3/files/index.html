00 / 先认识它

大嘴只是
故事的开场。

鹈鹕是鹈鹕科、鹈鹕属的大型水鸟。它们最醒目的工具，是长喙下方可以伸展的喉囊；真正让它适应水域生活的，却是喙、蹼足与宽大翅膀的共同配合。

不同物种住在不同的水域，也有不同的捕鱼方式。认识鹈鹕，不能把一种鸟的习惯套在整个类群上。

01

THE POUCH

会伸展的喉囊

捕食时，喉囊兜住猎物和水；随后排出水，再吞咽食物。它不是把一天的鱼长期存起来的“冰箱”。

误解纠正喉囊 ≠ 长期储物袋

SPECIES PROFILE / 物种档案

褐鹈鹕

海岸与河口边的俯冲猎手。

在哪里遇见
常见于美洲沿岸和河口。
如何捕鱼
能从空中俯冲入水捕食。
繁殖笔记
可在地面或树上筑巢；双亲共同孵卵，并给雏鸟喂食。

俯冲是褐鹈鹕的捕食方式，不能推广为所有鹈鹕的统一动作。

03 / 晚餐时间

同一张嘴，
不同打法。

鱼是主要食物，但菜单不只一种；捕食策略也因物种与环境而异。

行为示意水面舀取

美洲白鹈鹕常在浅水水面捕食，用喙与喉囊舀取食物，而不是从空中扎入水中。

菜单备注

鱼是主食，不是全部。美洲白鹈鹕也会取食蝾螈、蝌蚪和小龙虾等；实际食谱受当地环境与食物供应影响。

04 / 群体生活

一起飞，
一起养育下一代。

鹈鹕常集群活动。美洲白鹈鹕可成群飞行，利用上升气流滑翔，也常在一起觅食。许多鹈鹕集群繁殖，但巢址存在物种差异。

FLIGHT / 飞行
⌁⌁⌁⌁⌁

借一阵上升气流

宽大的翅膀帮助滑翔。成群飞行时，天空也是它们移动与寻找食物的通道。

NEST / 繁殖

巢址不能一概而论

美洲白鹈鹕在地面筑巢；褐鹈鹕可在地面或树上筑巢。窝卵数、孵化时间等也不能套用单一物种。

FOOD WEB / 食物网

水域里的一环

作为捕食鱼类等动物的水鸟，鹈鹕也是水域食物网的一部分，而不是孤立于环境之外的“大嘴符号”。

05 / 让水域继续有朋友

一张大嘴，
装不下所有风险。

褐鹈鹕曾受农药污染影响，保护措施促进了恢复。但这不等于所有鹈鹕种群都没有风险。
