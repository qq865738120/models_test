# 布丁专送 · 8 秒追加阶段交付说明

- 最终入口：`output/index.html`，内联完整 SVG，`viewBox="0 0 640 480"`。
- 独立 SVG 源码：`output/animation.svg`；相同源码同时保留于 `solution/animation.svg`，供项目时间采样工具读取。
- 页面与 SVG 均无 JavaScript、外链、位图、网络依赖、存储或额外后端。所有展示样式内联；源码链接使用相对路径。

## 启动

在本题项目根目录运行：

```sh
python3 -m http.server 5173 --bind 127.0.0.1 --directory output
```

打开 `http://127.0.0.1:5173/`。端口仅为启动示例，交付文件不含固定端口逻辑。

## 八秒时序

| 时间 | 实际实现 |
| --- | --- |
| 0–4 秒 | 车身保持基准位置；地面向左移动，两轮转动，双脚踩踏。 |
| 4–5 秒 | 减速带先后通过前后轮；整辆车、骑手、货架一起向上轻颠两次，幅度分别约 7 和 5 个 SVG 单位，5 秒恢复基准位置。 |
| 5–6 秒 | 布丁仅沿竖直方向上升，5.5 秒达到 36 个单位高度，然后落回原来的固定托盘。托盘始终和货架固定连接。 |
| 6–8 秒 | 鹈鹕在 6–6.4 秒转头，6.4–7 秒向后看，7–7.4 秒转回，余下时间继续骑行；躯干和坐姿不变，两翅一直接触车把。 |

主事件使用 8 秒 SMIL；平稳骑行比初始版延长 2 秒，颠簸、布丁腾落、回头事件的时长仍分别为 1、1、2 秒，先后顺序不变。轮辐周期为 1 秒，踏板、蹼足与双腿统一为 1.6 秒（每 8 秒正好 5 圈），地面纹理为 0.5 秒，均整除 8 秒。布丁的竖直位移始终不大于零，其主体底面为 y=263、描边到 y=264，托盘接触面为 y=264，不向下穿过托盘。减速带在周期边界时均处于画外。

## 实际运行的验证

1. 本地 HTTP 服务实际打开入口与 SVG，均返回 200，类型分别为 `text/html` 和 `image/svg+xml`。
2. Python XML 解析与源码检查通过：正确 viewBox、一个内联 SVG、两个车轮实例，无 script/image/foreignObject、无外部资源引用；HTML 内联内容与两份独立 SVG 一致。
3. 在本地浏览器查看完整页面，查看运行中的骑行姿态，并暂停采样 5.5 秒的布丁腾空及 6.6 秒的回头画面；布丁、双翅、蹼足、完整自行车均可辨识。最终入口浏览器捕获的 warning/error 日志为空。
4. 复制项目提供的 `tools/svg-viewer.html` 到 `.runtime/check-phase2.html` 扩展采样，保留原工具不变。通过工具按钮调用浏览器原生 `pauseAnimations()`、`setCurrentTime()`，读取真实动画后的 `getCTM()`、`getBBox()` 与腿部路径端点。以 0.01 秒步长检查 0–24 秒，共 2401 个时刻，结果：
   - 主体包围盒始终在 640×480 画面内。
   - 布丁主体底面与托盘名义接触面的最小间距为 1 个单位（计入布丁外描边后为接触）；最大上升高度 36。
   - 双侧腿端点与各自蹼足踝点最大误差 0.4231 个单位，来自两个采样密度不同的分段插值。
   - 0、8、16、24 秒的车身高度、布丁高度、头部朝向和踝点连接误差一致。
   - 4.17 秒车身高度 -6.998，4.73 秒 -4.999；5.5 秒布丁高度 36；6.6 秒头部水平朝向系数 -1；7.9 秒恢复 +1。0、2、3.99、4 秒车身均无颠簸，布丁均静置托盘。
   - 双脚底部踏板中心与旋转曲柄两端最大距离误差 0.102 个单位；两脚与曲柄使用相同的 1.6 秒周期，相位相差半圈。
5. 实际打开 `.runtime/iframe.html`，以 `sandbox="allow-scripts"`、无 allow-same-origin 的 iframe 加载交付页面，确认画面与动画可显示。

复核采样工具可在项目根目录另开普通静态服务，访问 `/.runtime/check-phase2.html`，点击“运行连续几何检查”。测试工具中的 JavaScript 不属于交付 HTML 或 SVG。
