# 交付说明：鹈鹕骑车送布丁

## 入口与启动

- 入口：`output/index.html`（单文件，内联 SVG，无外链、无位图、无 JavaScript）。
- 本地启动：在项目根目录执行
  `python3 -m http.server 5173 --bind 127.0.0.1 --directory output`
  然后打开 `http://127.0.0.1:5173/`。也可直接以静态文件方式在浏览器打开。
- 页面无 localStorage / IndexedDB / Service Worker，也不读取父页面；可放在跨源展示 iframe 中运行。

## 实现摘要

- `viewBox="0 0 640 480"`，全部动画为 SMIL（27 个 animate/animateTransform 节点，均为 6s、无限循环）。
- 6s 时间线：0–2s 平稳骑行；2–3s 黄色条纹减速带经过车下、整车轻颠；3–4s 布丁离盘腾空并落回；4–6s 鹈鹕回头查看、恢复前视。
- 双轮每周期各转 720°，曲柄转 1080°（3 圈）。路面以 540px 宽的周期贴片滚动，6s 位移正好 540px；车轮/曲柄整数圈、贴片周期性保证循环无缝。
- 双翅分别落在两个车把握把上；身体、双腿、托盘均在同一 `bikeRig` 内，颠动时整体移动，连接不脱开。
- 双腿用两段式解析 IK 逐帧求解（每周期 48 个采样点，共 49 个 `d` 值）：脚踝坐标严格等于曲柄对侧踏板位置（踏板上方 9px），左右脚相差 180°；脚掌几何体本身固定在踏板组内并反向旋转保持水平。
- 布丁只在 3–4s 做向上平移（相对托盘 keyframe y 偏移始终 ≤0），3.0s、4.0s 及以后均为 0；最大升程 58px，峰值约 3.63s，旋转在落回时为 0。

## 已实际检查

1. **文件结构**：解析内联 SVG 通过；`viewBox` 为 0 0 640 480；无 `<script>`、无外链 URL、无 `<image>`/位图。
2. **动画时长**：全部 27 个 SMIL 节点 dur 均为 6s；无 JS 定时器。
3. **踏板四相位**：用无头 Chromium 逐帧截取 t=0、0.5、1.0、1.5s，确认近侧脚依次位于右/下/左/上，远侧脚处于相反相位；腿部 IK 数值检查显示近腿最大需长 105.7px、远腿 112.8px，均小于骨长和 118px，49 个采样点首尾相同。
4. **事件边界**：截图核对 t=0.5s（平稳）、2.4s（整车抬起、减速带在车下）、3.6s（布丁在空中、托盘原位）、4.7s（头朝后查看、喙指向左下方）、5.99s（已恢复前视）。
5. **布丁与托盘**：keyTimes/values 检查：3.0s 前与 4.0s 后 translateY=0；飞行段所有偏移为负（向上），无向下穿透；托盘与货架夹具始终同组。
6. **循环与三周期**：以 `svg.setCurrentTime()` 暂停取帧，比较 t=0.2 / 6.2 / 12.2 / 18.2s；0.2 与后三者像素差最大 3/255，>8 的像素占比 0%，无漂移、无交界突跳。2.4s 与 8.4s 的差仅 0.0026% 像素（边缘抗锯齿级别）。
7. **静态服务器 / iframe**：`python3 -m http.server 5173 --directory output` 返回 HTTP 200，完整页面在 1200×980 视口截图正常，时间线卡片与 SVG 均显示。另以 5174 端口的项目根服务承载 wrapper，用 `<iframe>` 指向 5173 的作品页面实测，SVG 与页面样式正常渲染（iframe 视口内的页面底部按 900px 高度自然截断，可滚动）。

## 未检查 / 已知限制

- 只在 **Chromium 155（无头）** 中实测；未测 Safari / Firefox 的 SMIL 表现。
- 未做 18 秒实时播放录像，三周期检查通过逐时刻 seek 取帧完成；两者在 SMIL 时间轴上等价。
- 远侧腿脚在部分阶段会被车架或近侧腿遮挡（几何接触仍成立）；以深橙色与近腿区分。
- 回头动作采用快速水平镜像翻转（约 0.36s 的二次元“甩头”），翻转瞬间头部会短暂压扁；这是有意的卡通表现，不是断连。
- 无交互控件（题目为纯动画，不要求操作）。

## 验证工具说明

截图/循环检查在 `.runtime/` 内用额外的 seek 页面完成；该页面注入 JS 仅用于把交付 SVG 暂停到指定时间，**不进入 `output/index.html`**。交付文件本身不含 JavaScript。
