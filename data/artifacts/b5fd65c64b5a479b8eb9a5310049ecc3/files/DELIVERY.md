# 鹈鹕快递大作战 · 海风邮局

## 入口与运行

- 入口：`output/index.html`。全部脚本、样式和 SVG 资源均在 `output/` 内，以相对路径加载。
- 已执行 `npm run build`，TypeScript 检查及生产构建成功。
- 本地预览：`npm run preview -- --port 23451`；端口可替换。也可对 `output/` 使用任意本地静态 HTTP 服务。
- 无额外后端、外网请求或持久化存储。已在 `sandbox="allow-scripts"`、不授予同源身份的 iframe 中运行；承载服务须按材料约定允许资源跨来源读取。
- 操作：方向键 / A、D 移动，空格跳跃，P / Esc 暂停。手机提供左右、跳跃按钮。音效可在右上角开启。

## 材料缺项与实现范围

所提供的 `materials/level.json` 仅含资源说明元数据，未包含平台、快递、机器人、危险区坐标或固定运动参数；`CONTRACT.md` 也明确未预设关卡布局。因此本实现自主设计了三段连续海湾关卡，未修改任何原始材料。重力保留起始工程的 900；水平速度 270，跳跃初速度 -580，世界尺寸 3380×720。关卡声明位于 `src/main.ts` 开头，平台用左上角、角色/机器人/快递用底部中心定位。

使用提供的全部角色动作、机器人、平台、危险区、快递与生命 SVG；行走动画为 8 fps。交付素材已与 `public/materials/` 逐文件比较，字节一致。背景、灯塔、建筑、植被、水面与特效为本地程序绘制。

## 实际检查结果

所有游戏操作均通过浏览器的普通键盘/界面输入完成，没有直接设置角色位置、快递数、剩余时间或胜负状态。

| 检查 | 实际结果 |
| --- | --- |
| 完整通关 | 收集三份快递后进入灯塔，显示胜利；剩余 85 秒、2 点生命。截图：`evidence/victory.png`。 |
| 开始前与结算后 | 开始前保持 120 秒；胜利后再次输入移动，界面与结果未改变。 |
| 跳跃与实体平台 | 实际跳过各段高台；空中再次按跳跃未获得第二次起跳；平台底部、侧面有实体碰撞。 |
| 移动平台 | 两座渡台均实际搭乘；第一座站立不输入，往返两端时持续承载角色。 |
| 持续接触与生命失败 | 站在机器人巡逻路径上，逐次受伤后体力归零，显示体力耗尽原因；没有接触一帧立即扣尽生命。最终构建再次检查，见 `evidence/life-failure.png`。 |
| 暂停 10 秒 | 在渡台上暂停，时间保持 107 秒；另外在受伤无敌期间暂停 10 秒，前后整页截图字节完全一致，恢复接触 250 ms 后仍为 2 点生命。 |
| 落水保留 | 拿到第一份快递后走入海湾，回到起点：2 点生命、1/3 快递、115 秒，快递与时间均保留。 |
| 未集齐出口 | 2/3 快递时进入灯塔，没有胜利，提示“还差 1 份快递”。之后返回取齐，完成该局。 |
| 超时失败 | 在起点等待完整倒计时自然归零，显示“派送时间到了”，生命仍为 3；见 `evidence/timeout.png`。 |
| 连续重开 10 次 | 从暂停页连续重开十次，每次均检查到 120 秒、0/3 快递、3 点生命；场景重新回到起点。 |
| 桌面与手机 | 实际检查 1280×720；在宽 390、高 844 的 iframe 中检查开始、游玩、暂停和 HUD。手机按钮配合方向输入成功拾取快递，见 `evidence/mobile.png`。 |
| 按钮释放、焦点与短按 | 检查按压释放、拖离控件导致焦点丢失后的清理；恢复后没有继续移动。短按 P 可暂停。 |
| 构建与资源 | 最终生产构建成功；本地静态 HTTP 可访问；手机 sandbox 预览控制台未发现错误或警告。 |
