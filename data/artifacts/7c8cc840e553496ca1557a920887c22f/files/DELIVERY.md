# 鹈鹕叉车驾校

入口：`output/index.html`。全部脚本、样式、程序化图形与本地 Ammo 运行资源都在 output 内，无外网请求、无账户或持久化存储、无应用后端。

构建：项目根目录 `npm run build`。预览：`npm run preview -- --port 56243`，打开对应本地地址。output 也可以独立放到任意静态 HTTP 服务。沙箱 iframe 的资源服务需允许跨来源读取；本地复核可用 `python3 solution/serve.py`，打开 `http://127.0.0.1:56244/qa/iframe-check.html`。

操作：W/S 前后，A/D 转向，E 升叉，Q 降叉，空格制动，Shift 低速微调，P 暂停，C 切换镜头。暂停菜单支持四向模型检查、拖动与滚轮。F3 打开本地性能诊断。

已检查：生产构建；真实按键驾驶、制动、车箱碰撞、载货撞墙；对齐托举、落地释放；错色、悬空、驶过不计分；三箱完整通关；暂停冻结；120 秒超时；结算冻结；十次重开；四向模型；无同源身份 iframe 启动与驾驶。

最终实测：三箱通关用时 32.7 秒；1280×720 / DPR 1，10 秒预热 + 60 秒采样，共 7200 帧间隔，P95 9.3 ms。预热后的连续十次重开均为 108 几何体、32 纹理、4 程序、11 刚体，无持续增长。

完整参数及容差见 `PARAMETERS.md`。实测步骤、原始状态、帧间隔和十次重开资源值见 `qa/TEST_STEPS.md` 与 `qa/*.json`；四视角、开始、胜利、超时、iframe 截图也在 qa 中。

已知限制：车辆采用 Y 向约束的平面刚体驾驶，没有精确悬挂或侧翻；对齐后使用明确阈值的辅助归位，不是自由摩擦托盘模拟。检查展台隐藏仓库的渲染、保留全部世界状态。未在其他硬件、移动设备或旧浏览器上验证。

提供的 warehouse.json 和 CONTRACT.md 未给出固定尺寸或地图，本次自主设计的米制参数已如实列入 PARAMETERS.md；原材料未修改。
