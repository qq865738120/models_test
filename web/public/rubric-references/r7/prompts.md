# 主持人视觉参考 · r7

本目录包含五张 AI 生成的三档对照图，统一使用暖白、青绿、橙色和白鹈鹕题材。使用内置 `image_gen` 生成，随后通过同一工具定向修改；没有使用 Python、拼贴或其他工具修改图片像素。

| 文件 | 对应人工维度 |
| --- | --- |
| svg-expression.png | SVG 构图与动作表现、追加画面 |
| static-visual.png | 科普网页首屏、全页完成度、追加视觉融入 |
| dispatch-visual.png | 派单产品视觉 |
| game2d-visual.png | 2D 场景、角色与界面视觉 |
| game3d-visual.png | 3D 精细建模、材质灯光、追加画面 |

每张图从左至右为 0 / 5 / 10 分的完成度示意；界面通过 CSS 显示三个区域，原始 PNG 保持完整。完整生成提示词、修改提示词及内置工具返回的原始来源路径记录在同目录 `prompts.json`。

这些是主持人的校准示意，不是实际模型成绩、可运行交付或严格的分数判定依据。不同布局、风格和技术同样可以达到高分，不能以与图片相似程度评分。图片中的英文、业务字段和示意内容不构成题目要求。

静态图不能证明动画同步、交互恢复或游戏手感。派单交互和 2D 手感由 `VisualReference.tsx` 中的代码 SVG 展示三档流程/动作示意，评分仍须实际操作。知识准确性等未覆盖的人工项继续使用原来的短文本标准。

这些文件仅位于主持人 Web 资源目录；不复制到参赛模板、公开材料、准备包或单题工作区。
